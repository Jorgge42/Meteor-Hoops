# TIDEFANG SCHOOL — DESIGN DE GAMEPLAY

## Fantasia
Uma escola que joga como uma corrente marítima: a bola muda de lado até a defesa perder o eixo.

## Lição de basquete
**Weak side awareness / inversão de lado.**

O jogador deve aprender que defender não é apenas perseguir o portador da bola. É necessário antecipar o próximo passe e proteger o lado fraco.

## Elenco
- Riptide — Spinosaurus / Armador / passe 92.
- Coral — Suchomimus / Ala / arremesso 84.
- Reef — Baryonyx / Pivô / defesa 87.
- Splash — Gallimimus / Ala reserva / velocidade 91.
- Brine — Irritator / Pivô reserva / força 92.

## Regras de IA desta build
- Em pressão moderada, o portador prefere inverter em vez de forçar arremesso.
- Passe Tidefang recebe multiplicador de velocidade.
- Alas alternam lado fraco em ciclos.
- Defensores fazem pequenas rotações laterais.

## Limite atual
Ainda não existe sistema completo de ajuda-e-recuperação, handoff ou skip pass com animação própria. A v0.6 testa apenas se a identidade é legível usando os sistemas existentes.
