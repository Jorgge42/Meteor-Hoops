# PLAYBOOK — Vale Fóssil v0.5

O sistema de jogadas é deliberadamente pequeno. O objetivo é ensinar decisões, não memorizar diagramas.

## LIVRE
Spacing padrão. Use para ler a defesa e improvisar.

## GIVE & GO
1. Chame a jogada com **C** até aparecer `GIVE & GO`.
2. Passe a bola.
3. O passador vira IA por uma janela curta e corta para o aro.
4. O novo portador pode devolver o passe ou atacar a ajuda defensiva.

Teste de design: a defesa deve precisar escolher entre acompanhar o cortador ou conter a bola.

## BACKDOOR
O ala oscila entre perímetro e corte profundo. A jogada existe para punir defensores que pressionam demais a linha de passe.

Teste de design: o movimento precisa ser visível antes de ser eficiente. Se o jogador não entende por que o ala sumiu, a jogada falhou visualmente.

## ABRIR QUADRA
Os alas ocupam posições laterais mais largas. É a chamada para infiltração de Kiro ou finalização física de Mako.

Teste de design: deve abrir corredor sem transformar os companheiros em espectadores imóveis.

## Evolução futura
- corta-luz real com colisão/ângulo;
- handoff;
- flare screen;
- escolha de quem executa a jogada;
- ícones temporários no chão mostrando intenção;
- playbook específico por escola.
